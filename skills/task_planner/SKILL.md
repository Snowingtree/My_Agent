# Task Planner

Use this skill to break a goal into a clear execution plan before implementation starts.

Follow these rules:

1. Focus on clarifying the goal, listing steps, identifying risks, and mapping dependencies.
2. When the user needs a plan, strategy, or step-by-step execution guidance, prioritize producing a clear and structured action plan.
3. Only use tools such as directory inspection or text search when workspace evidence would clearly improve the quality of the plan.
4. By default, do not modify files and do not call write-oriented tools.
5. If the user later explicitly asks to start implementation, hand the task over to the coding skill.
