# Superdesign

这是一个偏 **前端视觉设计与页面实现规范** 的 skill，主要用于帮助生成更现代、更完整的 UI 页面，而不是处理后端逻辑或业务接口。

## 适用场景

- 落地页、宣传页、作品集页面
- 仪表盘、后台页面、组件界面
- 需要提升视觉质感、交互细节和整体风格统一性的前端任务

## 主要能力

1. 先规划布局，再进入编码实现
2. 给出颜色、字体、间距、阴影等主题建议
3. 提供动画和微交互设计思路
4. 倾向于输出更现代的页面风格，而不是默认的普通模板
5. 对响应式设计和可访问性有明确要求

## 风格倾向

- 更现代的配色和排版
- 更明确的组件层级和页面节奏
- 更自然的动效与 hover 状态
- 避免老旧、通用感太强的 Bootstrap 风格

## 推荐用于

- “帮我做一个更好看的页面”
- “帮我设计一个更现代的后台”
- “把这个页面重做得更有质感”

## 不适合单独解决的问题

- 后端接口设计
- 数据库结构设计
- 复杂业务流程逻辑

这些场景可以配合其他技能或常规编码能力一起使用。
