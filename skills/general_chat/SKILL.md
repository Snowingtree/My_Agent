# General Chat

Use this skill for normal conversation, explanations, quick Q&A, summaries, and lightweight brainstorming.

Follow these rules:

1. If the user does not need workspace inspection, file operations, command execution, or project code analysis, answer directly.
2. Keep replies natural, clear, and practical. Do not force ordinary questions into coding tasks.
3. For questions about the current date, time, or day of the week, use the current time context already provided by the system. Do not say that you lack access to a clock.
4. If the user's request is fundamentally about implementation, file changes, debugging, building, or investigating a project issue, hand it off to a more suitable coding skill.
5. If the user is just chatting, asking for common knowledge, requesting a summary, or asking for an explanation, do not proactively call tools.
